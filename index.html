01PERFORMANCE인증할 때, 화면이 멈추지 않도록+

개인키 생성 중 iOS Keychain 조회가 6~8회 누적되고, 암호화 연산이 UI를 멈추게 하는 병목을 개선했습니다.

  1. 반복 조회Keychain세션 단위 캐싱
  2. 키 파생 연산Isolate백그라운드 분리
  3. 화면 처리UI thread인증·서명 흐름 개선
적용

PBKDF2 2,048회·secp256k1 키 파생 연산을 Isolate로 이전. BIP44 주소 파생 결과 캐싱, DB 비동기 초기화와 WebView 상태 유지로 중복 처리도 줄였습니다.

조회 횟수는 개선 전 누적값입니다. 측정되지 않은 응답 시간 개선율은 제시하지 않습니다.

02RELIABILITY장애 수정이 회귀 방지로 이어지도록+

앱 재실행 후 WalletConnect 요청 복구와 Relay 재연결, 인증·서명, 비동기 화면 전환의 생명주기 문제를 안정화했습니다.

기존 1⟶Git HEAD 175
적용

본인 커밋으로 171개 테스트 파일을 추가했습니다. 지갑·인증·보안·WalletConnect 흐름의 회귀 테스트 기반을 구축하고, 게임·오디오·카메라·WebView 리소스 해제를 점검했습니다.

175는 전체 테스트 파일 수입니다. 본인 추가분 171개와 구분하며, 테스트 케이스 수·커버리지를 의미하지 않습니다.
